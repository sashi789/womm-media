Every app retried. The server never recovered. | How does a retry loop make an outage worse?

A realistic scenario with made-up numbers, not a claim about any company: a server handles 1,000 requests a second and normally gets 800. A database hiccup lasts 10 seconds and requests start timing out.

Why it gets worse:
1. Each app retries a timed-out request at once, up to 3 more times, so one request can become 4
2. Load jumps to a few thousand a second, the server is buried, more requests time out, and those are retried too
3. The database is back, but the extra load keeps the server down

The fix:
1. Exponential backoff: wait longer after each failure (1s, 2s, 4s)
2. Jitter: add a random bit so apps don't retry together
3. Cap the retries, then show an error
