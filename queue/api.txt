Your weather app doesn't know the weather | So how does it tell you? APIs explained

It asks another computer, using the agreed rules called an API. Think of a restaurant: you (your app) tell the waiter (the API) what you want, and the kitchen (the other system) prepares it. The menu is everything you're allowed to ask for.

One real request, step by step:
GET /weather?city=Mumbai
- GET: I want to read something
- /weather: which item on the menu
- city=Mumbai: your details
The server replies with a status code, 200 OK, and the data, usually JSON.

Status codes: 200 it worked, 404 not found, 500 the server has a problem. Codes starting with 4 are your mistake, codes starting with 5 are theirs.

Most APIs also use an API key (your ID card, so they know who is asking) and limit how often you can ask. Ask too fast and you get 429 Too Many Requests.
