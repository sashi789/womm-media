Websites don't have names. Only numbers. | How DNS turns a name into an address

Every computer on the internet has a number address, called an IP address. DNS is the system that turns the name you type into that number.

The journey of one lookup (example.com):
1. Your phone asks a resolver, usually run by your internet provider
2. The resolver asks a root server: who handles .com?
3. The .com servers point to the site's own name server
4. That name server answers with the address
5. The resolver sends it back to you, and your browser connects

Answers are remembered for a set time called the TTL, so the next visit skips the journey. It also means that when a site changes its address, old answers can linger until they expire.

When DNS breaks, the server can be perfectly fine and nobody can reach it. Engineers joke: it's always DNS.

The address 203.0.113.7 is an example from a range reserved for documentation.
Sources: IETF RFC 1034 (Domain Names: Concepts and Facilities), RFC 5737 (Documentation address blocks).
